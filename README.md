# 奶奶的菜谱

> 一款关于记忆、味道与陪伴的文字冒险游戏。
> 小红花赛道参赛作品。

---

## 📖 游戏简介

寒假，大学生小秋回到奶奶家。
推开那扇暗红色的铁门，她发现——奶奶开始忘了事。
盐罐里放着糖，糖罐里放着盐。电视开着却没声音。
最让她难过的是，奶奶看着她的眼神，像在努力拼起一幅打乱的拼图。

床头柜上有一本泛黄的旧菜谱，2003 年——小秋出生那年——奶奶写下：
*"等你长大，奶奶教你做菜。以后不管走到哪，都能自己给自己做饭吃。"*

这一次，小秋决定不只是等着吃奶奶做的菜。
她要学会这本菜谱里的每一道菜。

**《奶奶的菜谱》** 讲述了小秋用七天时间学做七道菜的故事。
每一道菜背后，都藏着一段跨越六十年岁月的家族记忆。
玩家通过选择切菜、火候、调味的方式，影响"陪伴感"数值，最终走向不同的结局。

---

## 🎮 玩法说明

- **叙事驱动**：以对话和内心独白推进剧情。
- **选择影响结局**：每章的关键选择会增减"陪伴感"（0-100）。
- **七道菜 = 七段故事**：每道菜对应一个年代、一段回忆。
- **三种结局**：根据最终的陪伴感，触发好结局 / 普通结局 / 感人结局。
- **CG 画廊**：收集奶奶人生中的老照片。
- **片尾科普**：关于阿尔兹海默症的早期识别与陪伴建议。

## 💻 运行环境

- **引擎**：[Ren'Py](https://www.renpy.org/) 8.5+
- **平台**：Windows / macOS / Linux

### 从源码运行

1. 安装 [Ren'Py SDK](https://www.renpy.org/latest.html)（8.5 或更高版本）。
2. 启动 Ren'Py 启动器，点击"preferences（设置）"→"Projects Directory（项目目录）"，选择 `the_grandmas_recipe` 的**上级目录**作为项目目录。
3. 在项目列表中选择"The Grandma's Recipe"或"the_grandmas_recipe"。
4. 点击"Launch Project（启动项目）"即可运行游戏。

## 🎨 资源说明

### 立绘命名规范

角色立绘统一放在 `game/images/characters/` 目录，命名格式为 `角色名_状态.png`（如 `qiu_neutral.png`、`grandma_neutral.png`）。立绘定义集中在 [script.rpy](game/script.rpy)，新增立绘只需把图片放入该目录，并在 `script.rpy` 中对应的 `image` 语句替换为新路径。

### 背景图命名规范

背景图放在 `game/images/` 根目录，命名格式为 `bg_名称.png`。

### CG 图命名规范

CG 图放在 `game/images/` 根目录，命名格式为 `cgXX.png`（XX 为两位数字，对应 `cg_gallery` 字典的 key）。

## 🤝 公益信息

本游戏关注阿尔兹海默症（认知症）患者及其家庭。片尾字幕中展示了一个二维码，引导玩家了解"认知症友好社区公益项目"。


### 认知症早期识别

如果家人出现以下情况，请及时带他们去医院检查，早期干预可有效延缓病情：

1. 经常忘记关火、关水
2. 反复询问同样的问题
3. 忘记回家的路
4. 性格突然变得多疑或暴躁

> 陪伴，是最好的治疗。
